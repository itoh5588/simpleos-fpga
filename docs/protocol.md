# UARTプロトコルとSYSCALL

FPGAのUARTモニター（`rtl/simpleos_os_core.vhd`）とPCホスト（`tools/simpleos_host.py`）は、次のバイナリーのパケットでやり取りする。数値はビッグエンディアン、和はデータの8bit加算。

## パケット

| 方向 | パケット | 意味 |
|---|---|---|
| FPGA→PC | `B` | 起動完了。DDR3の較正済みで、CPUは停止中 |
| FPGA→PC | `S` 番号(2) R8(4) R9(4) | SYSCALLが発生した。CPUは `C` を受けるまで止まる |
| FPGA→PC | `H` 状態(1) | CPUが停止した。bit0が1ならフォルト停止 |
| PC→FPGA | `W` 番地(3) 長さ(2) データ 和(1) | 物理メモリーへ書く。正しく受けたら `K`、和の不一致や受信異常なら `E` |
| PC→FPGA | `R` 番地(3) 長さ(2) | 物理メモリーを読む。データの後に和を返す |
| PC→FPGA | `G` | 全16レジスタを4バイトずつ返す（R0〜R9、TP、SP、PC、PT、VT、CR） |
| PC→FPGA | `C` フラグ(1) 値(4) | SYSCALLを終える。bit0：R8に値を書く。bit1：PCをスタックに積んで0番地へ分岐する |
| PC→FPGA | `X` | CPUを起動する |
| PC→FPGA | `Z` | 主記憶1MiBをすべて0にし、終わったら `K` |
| PC→FPGA | BREAK | 回路をリセットして `B` に戻る |

番地は下位20bitを使う。

## 受け付ける状態

| 状態 | 受け付けるコマンド |
|---|---|
| ローダー（`B` の後） | `W`、`R`、`G`、`X`、`Z` |
| CPU実行中 | なし（`S` か `H` を待つ） |
| SYSCALLの応答待ち（`S` の後） | `W`、`R`、`G`、`C` |
| 停止後（`H` の後） | `W`、`R`、`G`。レジスタは停止時の値を保つ |

受け付けないコマンドには `E` を返す。停止後に再び動かすときはBREAKを送る。

## 起動の手順

1. BREAKを送り、`B` を待つ。
2. `Z` で主記憶を0にする。DDR3の電源投入時の内容は不定なので、`emu.py` と同じ「すべて0」の状態を作る。
3. `os.bin` を `W` で番地0から書く。`os.bin` は約1MiBあるが大半は0なので、PCホストは0だけの4KiBブロックを送らない。
4. 4つのタスクのページ表（`0xFFF00`〜`0xFFF3F`）を、`emu.py` と同じ内容で書く。
5. `X` でCPUを起動する。初期状態はSP=0xFF000、PC=0x80000、MMU無効。

## SYSCALLの処理

| 番号 | 機能 | 処理する側と方法 |
|---|---|---|
| 0 | 1文字表示 | PC。R8の下位8bitを表示 |
| 1 | 文字列表示 | PC。R8が指す論理番地からNUL終端の文字列を `R` で読む |
| 2 | 書式付き数値表示 | PC。R9が指す書式文字列で、Pythonの `format(R8, 書式)` |
| 3 | キー入力 | PC。そのタスクの仮想コンソールのキーを最大5ms待ち、なければ0。`C` でR8へ |
| 10 | 現在時刻 | PC。Unix時刻を `C` でR8へ |
| 11 | 日時表示 | PC。R8＋TP/10を日時にして表示（TPは `G` で読む） |
| 20 | レジスタ表示 | PC。`G` で読んだ全レジスタを表示 |
| 21 | ファイル一覧 | PC。プログラム用ディレクトリーのファイル名を表示 |
| 22 | プログラム実行 | PC。ファイルを物理番地0へ `W` で書き、`C` のbit1でCPUにPCを積ませて0番地へ分岐させる |
| 23 | タスクのロード | PC。タスクのページ表からページ0の物理ページを `R` で調べ、そこへ最大64KiBを `W` で書く |
| 30 | 現在タスクの設定 | PC。表示と入力に使う仮想コンソールを切り替える |
| 40 | メモリーダンプ | PC。256バイトを読んで表示。R9のbit0が1なら論理番地、0なら物理番地 |
| 41 | フォルト番地 | CPU。最後のページフォルトの論理番地をR8へ。PCへは送らない |

文字列とダンプで論理番地を使うSYSCALL（1、2、11、20、22、23、40）では、PCホストは先に `G` でレジスタを読む。MMUが有効（CRのbit31）なら、PTが指すページ表を `R` で読み、`emu.py` と同じ方法で論理番地を物理番地に変換する。

上の一覧にない番号では、`emu.py` と同じく「Syscall n not implement yet.」と表示して処理を終える。

## 停止

- HALTでは `H` と状態0を送る。PCホストは `G` でレジスタを読み、`emu.py` と同じく「CPU halted.」と全レジスタを表示する。
- 未定義の命令などでCPUがフォルト停止すると、状態のbit0が1になり、LD5が点灯する。
